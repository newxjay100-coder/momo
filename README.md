# Car roof jump — CozyClay

CozyClay 장면에서 캐릭터가 차 지붕으로 올라가 점프하고, 점프 구간을 절반 속도로 늦춰 지붕에 착지합니다. 착지 순간 발과 지붕을 클로즈업한 뒤 마지막에 측면 와이드 샷으로 줌 아웃합니다.

- `City Block.cclayproject` — 장면, 측면 카메라, 슬로모션과 착지 클로즈업이 포함된 프로젝트. CozyClay의 **File → Open**에서 엽니다.
- `car-roof-jump.motion.json` — 점프 동작의 원본 모션 설정.
- `preview.png` — 측면 시점에서 본 지붕 위 점프 장면 미리보기.

현재 캐릭터는 CozyClay 기본 Y Bot 모델입니다. 첨부되었던 인물 사진은 아직 캐릭터 외형에 적용되지 않았으며 이 저장소에 포함하지 않았습니다.
