# Car roof jump — CozyClay

CozyClay 장면에서 캐릭터가 차 지붕으로 올라가 점프한 뒤 다시 지붕에 착지합니다. 카메라는 이동부터 착지까지 차 옆면이 보이는 측면 시점으로 따라갑니다.

- `City Block.cclayproject` — 장면, 카메라, 195프레임 모션이 포함된 프로젝트. CozyClay의 **File → Open**에서 엽니다.
- `car-roof-jump.motion.json` — 점프 동작의 원본 모션 설정.
- `preview.png` — 측면 시점에서 본 지붕 위 점프와 착지 장면 미리보기.

현재 캐릭터는 CozyClay 기본 Y Bot 모델입니다. 첨부되었던 인물 사진은 아직 캐릭터 외형에 적용되지 않았으며 이 저장소에 포함하지 않았습니다.
